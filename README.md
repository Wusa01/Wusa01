## 🚀 Featured project

### [🇹🇩 Chad Civil Registry](https://github.com/Wusa01/Chad_Civil_Registry)
A web system to manage civil records: births, marriages, deaths and divorces.

- 4 levels levels (admin, regional manager, officer, citizen)
- Two-factor authentication (2FA) and CSRF protection
- PDF documents with QR code verification
- Citizen portal to follow requests using the national ID (NNI)
- Arabic / French interface
- Digital archive, reports and backups

**Stack:** Python · Flask · SQLAlchemy · Alembic · ReportLab · WeasyPrint
